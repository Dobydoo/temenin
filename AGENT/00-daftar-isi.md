# Paket Dokumen Temenin
Versi paket 0.1. Dirapikan 27 Oktober 2026. Enam dokumen resmi Temenin untuk Meta Global AI Developer Hackathon dan kelanjutan produk setelahnya.

1. **01-brand-identity-temenin.md** — Nama, logo dan filosofinya, color palette, tagline final "Vibes click. Plans stick.", target pengguna, aturan privasi, keunggulan dan pembeda, kepribadian brand, tipografi, aturan pakai logo, gaya ikon.
2. **02-layout-guide-temenin.md** — Panduan layout web mobile dan desktop: breakpoint, kontainer, ukuran logo, navigasi, skala teks, button, kartu, form, blok Aturan Main, pita jarak.
3. **03-rencana-pengembangan-temenin.md** — Positioning, cerita demo 7 langkah, scope MVP (must have, should have, dipotong), arsitektur, timeline per hari, risiko.
4. **04-prd-temenin.md** — Product Requirements Document: masalah, tujuan, target, prinsip produk, ruang lingkup, kebutuhan fungsional FR-01 sampai FR-30 (termasuk dark mode FR-29 dan FR-30), kebutuhan non-fungsional, risiko.
5. **05-erd-temenin.md** — Entity Relationship Diagram: diagram Mermaid, 14 entitas dengan atribut lengkap, relasi dan kardinalitas, catatan implementasi.
6. **06-uml-temenin.md** — Use Case Diagram (PlantUML), Class Diagram, Sequence Diagram alur demo, Activity Diagram verifikasi dan pengungkapan bertahap, State Diagram siklus hidup aktivitas.

Versi gabungan semua dokumen tersedia sebagai satu berkas DOCX: Temenin-Dokumen-Lengkap.docx.
Sumber dokumen yang hidup tetap berada di workspace goal hackathon; paket ini adalah salinan terbit per 27 Oktober 2026.
